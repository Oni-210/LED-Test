# FacePlayer
This is for expressions that have eyes and a mouth. It also includes a moving mouth with sound detection throug a microphone. It takes three parameters.

## eye_file
This is the file for the eyes. It is always shown.

## mouth_file
This is the file for the mouth. It is replayed with a talking mouth when sound is detected.

## talking_file
This is the talking mouth. It has 8 frames where the mouth opens more from frame to frame.
