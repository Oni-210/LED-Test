# Visuals

## Expression
This is an Enum for the different expressions.

## TempExpression
This is an Enum for temporary expressions.

## Color
This is a class for color information. It contains three bytes for each of the color values. It is meant to be used in an array to represent an image.

## Visual
This is the base class for visuals. The important thing is the run() function which renders the next frame and returns a pointer for a Color[].
